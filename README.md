# netpult

Один пульт для обхода блокировок: zapret, VPN и прокси Telegram в одном месте. Один бинарь, без рантайма и зависимостей.

```
  ОБХОД БЛОКИРОВОК

  ● zapret    ВКЛ    general_alt10.bat
  ○ VPN       ВЫКЛ
  ● Telegram  ВКЛ    192.168.1.10:1080

  [1] zapret вкл/выкл   [2] стратегия   [3] проверить
  [4] VPN               [5] Telegram    [6] QR на телефон
  [7] автоподбор        [8] раздача     [9] профиль сети
  [q] выход
```

`netpult` без аргументов открывает этот экран. С аргументами — обычные команды для скриптов.

## Команды

```
netpult                состояние и меню
netpult status         состояние всего сразу и внешний адрес
netpult test           проверить YouTube / Discord / Telegram и скорость

netpult on|off|toggle|restart     zapret
netpult strat                     список стратегий
netpult strat <номер|имя>         поставить стратегию

netpult vpn            открыть окно VPN-клиента
netpult vpn off        закрыть

netpult tg on|off      прокси Telegram
netpult tg qr          QR для телефона
netpult tg link        ссылки для компьютера и телефона

netpult tune           подобрать рабочую стратегию перебором
netpult tune --all     перебрать все, не останавливаясь на первой хорошей

netpult watch --once   один проход проверки прямо сейчас
netpult watch install  сторож в автозапуск
netpult watch log      что чинилось

netpult profile        какая сеть и что для неё сохранено
netpult profile save   запомнить состояние для этой сети
netpult profile apply  привести всё к профилю сети

netpult share on|off   прокси для телефона: весь его трафик через этот компьютер
netpult share status   адрес, порт, пароль и список подключённых устройств

netpult split on|off   через ноду только домены из списка, остальное напрямую
netpult split list     какие домены идут через ноду (свой + автосписок)
netpult split add <д>  добавить домен
netpult split update   обновить автосписок геоблока (itdoginfo, ~466 доменов)
netpult split log      что шло через ноду, а что напрямую

netpult tg qr --png [файл]   сохранить QR картинкой
```

## Автоподбор

`netpult tune` перебирает стратегии и смотрит не на теорию, а на факт: открывается ли YouTube и с какой скоростью отвечает CDN. Текущая проверяется первой — если она в порядке, ничего не меняется.

Скорость мерится дважды, берётся лучший замер, и рабочая стратегия не уступает место кандидату, пока тот не обгонит её в полтора раза. Без этого запаса пульт дёргал бы настройку из-за случайной просадки: в первом же прогоне рабочая стратегия показала 51 КБ/с на холодном соединении и 202 КБ/с на следующем замере.

## Сторож

`netpult watch install` ставит фоновую службу, которая раз в десять минут смотрит, живо ли всё, и чинит по лестнице от дешёвого к дорогому: поднять упавший прокси Telegram → включить выключенный zapret → перезапустить движок → подобрать другую стратегию. Каждый шаг пишется в журнал, `netpult watch log` его показывает.

Он же следит за сменой сети: пришёл в другое место — включается профиль этого места.

## Профили сетей

Профиль привязан к имени Wi-Fi (а если его не видно — к адресу шлюза) и помнит, что в этой сети должно быть включено. Настроил как надо, сказал `netpult profile save` — дальше пульт сам приведёт всё к этому виду, когда ты сюда вернёшься.

## Раздача на телефон

`netpult share on` поднимает HTTP-прокси на всю локальную сеть. В настройках Wi-Fi телефона указываешь узел и порт — и весь трафик телефона выходит в интернет с этого компьютера, а значит, проходит через zapret. Ни VPN, ни root на телефоне не нужны.

Прокси свой, без библиотек: `CONNECT` для HTTPS и обычные запросы для HTTP — это всё, что нужно настройкам Wi-Fi на Android и iOS.

**Раздача всегда под паролем.** Открытый прокси на всю сеть означал бы, что любой сосед по Wi-Fi выходит в интернет через тебя, — такого не нужно. Поэтому `net share on` требует пароль, и если ты его не задал, netpult заводит свой и показывает при включении. Пароль вводится в телефоне там же, где адрес прокси. Свой можно прописать в настройках (`share_password = ...`). Если очень надо открыть без пароля — только явной командой `net share open`.

## Сплит-прокси

`net split on` поднимает локальный прокси, который смотрит на имя каждого хоста: домен из списка — гонит через заграничную ноду, остальное — напрямую, без крюка за границу. Ровно как домашний роутер. По умолчанию через ноду идут сервисы, которые режут по стране (OpenAI, Anthropic, Gemini), а не по DPI, — их zapret не лечит, тут нужен именно заграничный выход.

Ноду сплит не расшифровывает и не поднимает сам. У Happ, когда выбрана нода и он работает в режиме прокси, уже слушает SOCKS на `127.0.0.1:10808` — туда сплит и отдаёт нужные домены. Так HWID-замок Happ не трогается, а ротация нод работает сама. Адрес ноды-SOCKS настраивается: `split_upstream = ...`.

Список — два файла: твой ручной `split-domains.list` (правится `net split add` или руками) и автосписок геоблока `split-geoblock.list`. Второй наполняет `net split update`: тянет `itdoginfo/allow-domains` (~466 доменов ушедших из РФ сервисов — JetBrains, Adobe, Cursor, DeepL, Tidal…) через зеркало jsDelivr, потому что GitHub raw из РФ без обхода недоступен. Сторож обновляет его раз в сутки. `net split log` показывает, что реально пошло через ноду, а что напрямую.

## Что умеет и на чём

| | Linux | Windows | macOS |
|---|---|---|---|
| обход DPI | `nfqws` через NFQUEUE | `winws` через WinDivert | `tpws` через PF, **только TCP** |
| VPN | определение туннеля, запуск клиента | то же | то же |
| прокси Telegram | да | да | да |
| QR на телефон | да | да | да |

Три бэкенда обхода — это один и тот же проект [zapret](https://github.com/bol-van/zapret), просто на разных системах он перехватывает трафик по-разному. Стратегии общие. На macOS у `tpws` нет UDP, поэтому QUIC и голос Discord этим способом не лечатся — это ограничение системы, а не утилиты.

Сейчас подключён бэкенд Linux. Windows и macOS определяются и показывают состояние, но переключение движка ещё не подведено — команды честно об этом говорят.

## Настройки

Всё определяется само: утилита ищет уже установленный zapret, бинарь `tglock-cli` и клиент Happ в обычных местах. Если что-то лежит иначе, можно указать явно в `config` рядом с состоянием (`~/.local/share/netpult/config`, на Windows `%LOCALAPPDATA%\netpult`, на macOS `~/Library/Application Support/netpult`):

```
zapret_dir = /home/deck/Apps/zapret-discord-youtube-linux-master
zapret_service = zapret_discord_youtube.service
tglock_bin = /home/deck/Apps/tglock/tglock-cli
tg_port = 1080
tg_lan = true
happ_bin = /opt/happ/bin/Happ
watch_interval_min = 10
share_port = 8899
share_password =
```

## Почему проверка идёт через curl

Стратегии zapret ломают часть TLS-клиентов. На `general_alt10` соединение rustls с `www.youtube.com` зависает намертво, тогда как curl, openssl и браузер проходят спокойно. Проверка на собственной криптобиблиотеке показывала бы «не открывается» там, где у человека всё работает, — поэтому запросы делает системный `curl`, который ведёт себя как настоящий клиент. Заодно в бинаре нет ни TLS-стека, ни его зависимостей.

## QR без зависимостей

`src/qr.rs` — свой кодировщик: байтовый режим, уровень коррекции L, версии 1–10 (до 271 байта). Матрицы сверены с libqrencode модуль в модуль, эталоны лежат в `tests/vectors.txt`, проверяются `cargo test`.

## Установка

Нужен собранный бинарь `netpult` и три внешних куска, которыми он управляет:
**zapret** (обход DPI), **tglock-cli** (прокси Telegram) и по желанию **Happ**
(VPN для геоблока и нода для сплита). netpult их не тащит за собой — он находит
уже установленное и рулит им.

### 1. Собрать бинарь

Нужен Rust (`rustup`) и системный компоновщик (`cc`/`gcc`).

```sh
git clone git@github.com:<твой-аккаунт>/netpult.git
cd netpult
cargo build --release
install -Dm755 target/release/netpult ~/.local/bin/netpult
```

Убедись, что `~/.local/bin` в `PATH`. Проверка:

```sh
netpult help
```

> **SteamOS:** корневая система read-only и без `cc`, поэтому Rust там не
> слинкует. Собирай в distrobox с тулчейном (`distrobox create --name dev`,
> внутри `dnf install gcc` / `pacman -S base-devel`), бинарь кладётся в общий
> `$HOME`, запускается на хосте. Внутри distrobox может не быть интернета к
> crates.io — тогда `cargo fetch` выполни на хосте, а в контейнере
> `cargo build --release --offline`.

### 2. zapret

Поставь [Sergeydigl3/zapret-discord-youtube-linux](https://github.com/Sergeydigl3/zapret-discord-youtube-linux)
по его инструкции (Linux; на Windows — winws из проекта Flowseal, на macOS —
tpws из bol-van/zapret). netpult сам найдёт его в обычных местах
(`~/Apps/...`, `~/Downloads/...`) по наличию `conf.env`. Служба на Linux
ожидается как `zapret_discord_youtube.service`.

Проверка: `netpult status` должен показать строку `zapret`.

### 3. tglock-cli (Telegram)

Скачай CLI-сборку под свою систему из релизов
[by-sonic/tglock](https://github.com/by-sonic/tglock) и положи, например, в
`~/Apps/tglock/tglock-cli` (на Windows — `tglock-cli.exe`). netpult найдёт его
там же или в `~/.local/share/netpult/`.

```sh
netpult tg on      # поднимет прокси и покажет QR
```

### 4. Happ (по желанию — для геоблока и сплита)

Поставь [Happ](https://github.com/Happ-proxy/happ-desktop), заведи подписку,
выбери ноду. Для сплита переведи Happ в режим прокси (не TUN), тогда он держит
локальный SOCKS `127.0.0.1:10808` — туда netpult и отдаёт домены из списка.

```sh
netpult vpn        # открыть окно клиента
netpult split on   # домены из списка через ноду, остальное напрямую
```

### 5. Автозапуск (Linux)

```sh
netpult watch install   # сторож: раз в 10 мин чинит упавшее, следит за сменой сети
```

### Ярлык на рабочий стол (KDE/Plasma)

`~/.local/share/applications/netpult.desktop`:

```ini
[Desktop Entry]
Type=Application
Name=Обход блокировок
Exec=konsole -e /home/ПОЛЬЗОВАТЕЛЬ/.local/bin/netpult menu
Icon=network-vpn
Terminal=false
Categories=Network;
```
